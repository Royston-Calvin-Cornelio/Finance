# Financial Data Analysis Project

## Overview

This project focuses on analyzing and transforming financial data using SQL, Python, Excel, and Power BI. The objective is to clean financial datasets, perform data validation and reconciliation, identify trends and discrepancies, and present meaningful insights through reports and dashboards.

## Objectives

- Clean and prepare financial datasets for analysis
- Perform data validation and reconciliation using SQL
- Analyze financial transactions and identify discrepancies
- Automate repetitive data-processing tasks using Python and VBA
- Create interactive dashboards and visualizations using Power BI
- Generate meaningful business insights from financial data

## Tools & Technologies

- SQL
- Python
- Microsoft Excel
- VBA
- Power BI
- Pandas
- Data Analysis & Visualization

- Data Cleaning & Transformation
- SQL Queries & Data Reconciliation
